# Chrome Web Store 上架文档

## 扩展名称

- **中文名**: VideoTracker - 视频观看进度记录器
- **英文名**: VideoTracker - Video Watch Progress Tracker

## 简短描述

> 自动记录 B站、YouTube、爱奇艺、腾讯视频的观看进度，支持一键跳转继续观看。纯本地存储，保护隐私。

（112 字符，符合 132 字符限制）

## 详细描述

```
VideoTracker 帮你轻松管理跨平台视频观看进度，再也不用担心忘记看到哪里了！

🎯 核心功能：

✅ 自动记录观看进度
  访问 B站、YouTube、爱奇艺、腾讯视频的播放页面时，自动记录视频信息和播放位置。

✅ 智能阈值过滤
  默认观看满 30 秒才记录，避免短暂浏览产生无效记录。阈值可自定义（0/10/30/60/120 秒）。

✅ 一键手动记录
  按 Ctrl+Shift+V 立即记录当前视频，无需等待阈值。

✅ 快速跳转继续观看
  点击记录即可打开对应页面，自动定位到上次播放位置。

✅ 搜索与筛选
  支持关键词搜索和按平台筛选，快速找到想继续观看的视频。

✅ 隐私优先
  所有数据纯本地存储，不联网、不收集任何数据。你的观看记录只属于你。

📺 支持平台：
  • B站 (bilibili.com)
  • YouTube (youtube.com)
  • 爱奇艺 (iqiyi.com)
  • 腾讯视频 (v.qq.com)

🔒 权限说明：
  • storage - 存储观看记录（本地）
  • activeTab - 读取当前标签页视频信息
  • tabs - 管理标签页跳转
  • commands - 注册快捷键

所有权限仅用于核心功能，不会用于任何其他目的。
```

## 隐私政策（简要版）

```
VideoTracker 隐私政策

最后更新：2026年5月

1. 数据存储
   VideoTracker 所有数据均存储在用户浏览器本地（chrome.storage.local），
   不会上传到任何外部服务器。

2. 数据收集
   VideoTracker 不收集、不传输、不分析用户的任何个人信息或浏览数据。

3. 网络访问
   VideoTracker 不进行任何网络请求，不与任何外部服务通信。

4. 权限使用
   - storage：用于本地存储观看记录
   - activeTab：用于读取当前标签页的视频信息
   - tabs：用于在用户点击记录时打开对应视频页面
   - commands：用于注册快捷键

5. 数据删除
   用户可随时在扩展内删除单条记录，或通过卸载扩展清除所有数据。

6. 联系方式
   如有隐私相关问题，请通过 GitHub Issues 反馈。
```

## 权限说明

| 权限 | 用途 | 必要性 |
|------|------|--------|
| `storage` | 使用 `chrome.storage.local` 存储观看记录数据 | 核心功能必需，所有记录保存在此 |
| `activeTab` | 读取当前活动标签页的内容，提取视频标题、播放进度等信息 | 核心功能必需，自动/手动记录依赖此权限 |
| `tabs` | 在用户点击记录时创建新标签页并跳转到对应视频页面 | 跳转功能必需 |
| `commands` | 注册全局快捷键 `Ctrl+Shift+V` 用于手动记录 | 快捷键功能必需 |

所有权限仅用于 VideoTracker 的核心功能，不会用于广告、数据收集或其他任何非功能目的。
