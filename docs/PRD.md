# VideoTracker PRD

## 项目概述
视频观看进度记录浏览器插件，自动/手动记录用户在各视频网站的观看进度。

## 核心功能

### P0（MVP）
| 编号 | 功能 | 说明 |
|------|------|------|
| F-001 | 视频信息自动提取 | 自动识别视频标题、集数、进度、URL、来源。支持最低观看时长阈值（默认30秒） |
| F-002 | 持久化存储 | chrome.storage.local 保存记录 |
| F-003 | Popup 快速预览 | 仅显示最近添加的 3 条记录，点击可跳转；点击「查看全部」进入 Options 管理页 |
| F-004 | 一键跳转继续观看 | 点击记录打开对应URL并定位时间点 |
| F-005 | 手动快速添加 | 快捷键 Ctrl+Shift+V 立即记录当前视频，操作成功后显示 Toast 提示 |
| F-006 | 设置与记录管理页 | 点击齿轮打开自定义 Options 页面（非 Chrome 扩展详情页），包含：<br>① 记录管理：查看全部记录、搜索筛选、删除<br>② 插件设置：自动记录开关、阈值设置(0/10/30/60/120秒)、快捷键显示<br>③ 站点管理：添加/删除自定义站点 |
| F-007 | 自定义站点管理 | 用户可手动添加自定义网站域名，插件会在该域名下尝试检测 HTML5 `<video>` 标签并记录。内置站点（B站/YouTube等）默认启用不可删除 |

### P1
F-008 进度自动更新 / F-009 手动编辑 / F-010 搜索筛选 / F-011 分组管理 / F-012 导入导出

### P2
F-013 进度可视化 / F-014 观看统计 / F-015 提醒 / F-016 云同步 / F-017 通用适配

## 自定义站点管理说明

### 内置站点
- bilibili.com（B站）
- youtube.com（YouTube）
- iqiyi.com（爱奇艺）
- v.qq.com（腾讯视频）

内置站点有专用适配器，能精确提取视频信息，**不可删除**，但可以关闭自动记录（通过插件设置总开关）。

### 自定义站点
- 用户可手动添加任意域名（如 `example.com`）
- 插件使用**通用适配器**（检测 HTML5 `<video>` 标签）
- 通用适配器能力有限：只能获取 `video.currentTime`、`video.duration`、`document.title`
- 自定义站点可随时删除

### Site Access 说明
Chrome 扩展默认只在声明的域名下运行。用户添加自定义站点后：
1. 插件将新域名保存到 `chrome.storage.local`
2. Content Script 通过 `host_permissions` 的 `<all_urls>` 或用户手动授权获得访问权限
3. 用户需在 `chrome://extensions` → 插件详情 → 「网站访问权限」中手动添加新域名

> **文档位置**：用户添加站点时，Options 页面会显示操作指引

## 平台适配
P0: B站(bilibili.com) / YouTube(youtube.com) / 爱奇艺(iqiyi.com) / 腾讯视频(v.qq.com) + 自定义站点
P1: 优酷 / 西瓜视频
P2: 通用HTML5 video（已作为自定义站点的回退方案）

## 数据结构

```typescript
interface WatchRecord {
  id: string;
  url: string;
  title: string;
  episode: string;
  seriesName?: string;
  platform: string;
  platformName: string;
  currentTime: number;
  duration: number;
  thumbnail?: string;
  lastWatchedAt: number;
  createdAt: number;
  notes?: string;
}

interface Settings {
  autoRecord: boolean;        // 自动记录开关
  threshold: number;          // 观看时长阈值（秒）
  customSites: CustomSite[];  // 自定义站点列表
}

interface CustomSite {
  domain: string;    // 域名，如 "example.com"
  enabled: boolean;  // 是否启用
  addedAt: number;   // 添加时间戳
}
```
