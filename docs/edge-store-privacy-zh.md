# Edge Add-ons 商店隐私表单填写内容（中文）

## 单一用途描述

VideoTracker 是一款视频观看进度记录工具，帮助用户自动保存和恢复在各视频网站的观看进度。扩展会通过心跳机制定期检测页面中的视频播放状态，当用户观看超过设定阈值后自动记录播放位置，下次打开同一页面时可快速定位到上次的观看位置。用户也可以通过快捷键手动保存当前进度，并可选择启用 Supabase 云同步功能在多设备间同步记录。

## 许可理由

### 存储理由

扩展使用 chrome.storage.local 存储以下数据：(1) 视频观看记录（URL、标题、播放进度、时间戳）；(2) 用户设置（自动记录开关、观看阈值、主题偏好）；(3) 自定义站点列表；(4) 云同步配置和认证令牌。所有数据均本地存储，不上传至任何服务器（除非用户主动启用云同步功能）。

### activeTab 对齐

用户点击扩展图标或使用快捷键手动保存当前视频进度时，需要获取当前活动标签页的信息（URL、标题）来创建准确的观看记录。activeTab 仅在用户主动交互时激活，不会在后台持续访问标签页。

### 标签的说明

tabs 权限用于：(1) 在用户切换标签页时检测视频播放状态变化，确保心跳机制仅在视频实际播放时运行；(2) 获取标签页的 URL 和标题信息，用于 iframe 嵌入播放器场景下将记录归因到正确的顶层页面；(3) 通过 chrome.tabs.sendMessage 与 content script 通信，通知自动保存成功。

### 命令的合理性

扩展注册了一个键盘快捷键 Ctrl+Shift+V（Mac 为 Cmd+Shift+V），用于让用户手动保存当前正在观看的视频进度。这是扩展核心功能的一部分，作为自动记录的补充，让用户可以在自动阈值未达到时主动保存。

### 脚本的合理性

扩展需要向网页注入 content script 来检测页面中的 HTML5 video 元素，读取 currentTime 和 duration 属性以获取播放进度。此外，通过 chrome.scripting.executeScript 在 MAIN world 注入桥接脚本，用于访问被 Shadow DOM 或 iframe 保护的播放器对象（如 B站、YouTube 等网站的嵌入播放器）。脚本不修改页面内容，仅读取播放状态。

### 身份证明

扩展使用 chrome.identity API 实现 OAuth 第三方登录功能。具体使用 chrome.identity.getRedirectURL() 生成 Supabase OAuth 回调地址，以及 chrome.identity.launchWebAuthFlow() 启动 Google 和 GitHub 的授权登录流程。用户登录后，扩展会获取访问令牌并存储在本地 chrome.storage.local 中，用于向用户的 Supabase 数据库同步观看记录。该功能完全可选，不登录也可正常使用本地记录功能，邮箱密码登录同样不依赖此权限。

### 主机权限的理由

扩展使用 *://*/* 主机权限以支持任意视频网站。扩展的核心价值是跨网站记录视频进度，用户可能在任何域名的网站上观看视频。内置适配器覆盖 B站、YouTube、爱奇艺、腾讯视频，同时支持用户自定义添加任意网站。content script 和 MAIN world 桥接脚本仅读取 video 元素的播放状态，不读取、修改或传输任何页面其他内容。

### 远程代码

不，我没有使用远程代码。

### 正当性（可选）

VideoTracker 是一款隐私友好的本地优先工具。所有数据存储在用户设备本地，不收集任何个人信息，不追踪用户行为，不使用分析服务。云同步功能使用用户自己的 Supabase 账户，开发者无法访问用户数据。扩展代码完全开源（https://github.com/Ankkaya/video-tracker），接受社区审查。
