# Edge Add-ons 商店隐私表单填写内容（中文）

适用版本：0.0.11。更新日期：2026-10-08。以下为本地提交材料，以实际功能和完整隐私政策为准。

## 单一用途描述

VideoTracker 保存和恢复用户在不同视频网站的观看进度，并通过可选的端到端加密同步在多设备间同步观看记录和站点规则。本地记录无需账号。自动记录默认关闭；用户开启后，达到设定的观看时长才自动保存。用户也可通过快捷键主动保存当前视频进度。

## 许可理由

### 存储理由

扩展使用 chrome.storage.local 在本地保存视频观看记录（网址、标题、播放位置与时长、观看时间、封面网址）、站点规则、删除标记、偏好设置、登录会话和同步数据密钥。观看记录默认保存在本地；注册或登录会与认证服务通信，用户选择同步时会上传加密数据。账号登录密码与同步加密密码不同，前者通过 HTTPS 发送至认证服务，后者不上传。

### activeTab 对齐

用户主动点击扩展或执行快捷键时，访问当前页面以识别并手动保存视频信息。activeTab 提供用户交互后的临时访问授权；自动记录另依赖网站访问权限及内容脚本。

### 标签的说明

tabs 权限用于读取相关标签页的网址和标题，将嵌入播放器的进度关联到正确的顶层页面，并识别第三方登录窗口中的相关标签页。扩展也使用标签页 API 打开观看记录和与内容脚本通信，但创建标签页或发送消息本身并非申请 tabs 权限的理由。

### 命令的合理性

扩展注册和查询手动保存快捷键 Ctrl+Shift+V（Mac 为 Command+Shift+V），让用户在未达到自动记录阈值或已关闭自动记录时主动保存进度。用户可在浏览器的扩展快捷键设置中调整快捷键。

### 脚本的合理性

扩展使用内容脚本及 chrome.scripting.executeScript 检测视频元素、页面上的播放时间和嵌入 frame 中的播放器状态，必要时在 MAIN world 执行扩展内置的播放器桥接脚本。记录功能还读取相关视频标题、网址、封面等信息；恢复播放会调整支持的播放器的播放位置，手动选择和恢复提示也会显示页面交互元素。

### 身份验证的理由

扩展使用 chrome.identity.getRedirectURL() 生成扩展回调地址，并通过 chrome.identity.launchWebAuthFlow() 启动用户主动选择的 Google 或 GitHub 授权登录。认证服务处理账号与会话信息，令牌保存在本地以维持会话。用户选择同步时，加密的观看记录上传至开发者配置的 Supabase 服务，并非用户自己托管的数据库。本地记录无需登录；邮箱密码登录不依赖 identity API。

### 主机权限的理由

*://*/* 网站访问权限用于跨网站视频识别与恢复播放。除 B站、YouTube、爱奇艺、腾讯视频外，还支持其他兼容 HTML5 视频网站及嵌入播放器域名，无法事先列出所有站点。脚本会读取相关视频标题、网址、封面、播放位置和时长等信息，并在支持的播放器中恢复进度。用户可关闭全局或单个站点的自动记录；站点规则控制自动记录行为，不等于撤销浏览器授予的网站访问权限。观看记录不是所有访问页面的完整浏览历史。

### 远程代码

不使用远程代码。用于检测播放器、记录和恢复进度的代码随扩展打包；认证、加密同步和封面加载属于网络数据请求。

### 数据使用目的

数据用于保存和恢复视频进度、账号认证和可选加密同步。VideoTracker 不使用广告追踪或分析服务，不出售数据，也不将数据用于无关画像、信用评估或借贷。

## 数据使用

根据提交后台字段核对个人身份信息、身份验证信息、网页浏览记录和网站内容等类别，覆盖实际处理的数据：

- 观看数据：视频网址、标题、播放位置与时长、观看时间、封面网址、站点规则、删除标记和偏好设置。
- 账号与认证数据：用户主动注册或登录时处理的邮箱、账号标识、认证凭据及会话信息；登录服务和第三方授权提供方按各自政策处理必要数据。
- 可选同步：用户开启同步或执行手动同步时，在设备端加密记录、站点规则和删除标记，再发送至开发者配置的 Supabase 服务。服务保存账号元数据、密文、受同步密码保护的数据密钥、盐值和加密参数。同步加密密码不上传，设备本地记住同步数据密钥。
- 连接信息：端到端加密不隐藏服务提供方正常处理的账号或 IP 地址等连接信息。即使未开启同步，加载远程视频封面也可能向图片提供方发送 IP 地址及请求的图片网址。

## 保留与删除

用户可关闭自动记录或同步、删除本地记录、退出登录。开启同步时，记录删除在下一次成功同步时传播。退出登录清除本地会话和同步解锁状态，保留本地记录。卸载清除插件本地存储，不会自动删除云端数据。

云端重置用新密钥及重新加密的本地数据替换旧云端快照和密钥，保留本地记录；其他设备需用新密码解锁。重置不等于删除账号，忘记同步密码后无法解密旧云端数据。云端账号元数据在账号存在期间保留；可联系开发者申请删除云端数据或账号。服务提供方的备份和日志可能有单独保留周期，不保证立即清除。
