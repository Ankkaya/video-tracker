核心功能

简单、高效、隐私优先的视频进度管理

🎯

自动记录

访问视频页面时自动记录播放进度，无需手动操作。智能阈值过滤，避免无效记录。

⌨️

快捷键保存

按 Ctrl+Shift+V 立即记录当前视频，无需等待阈值。操作成功后 Toast 提示。

🚀

一键继续观看

点击记录即可跳转到对应页面，自动定位到上次播放位置，无缝衔接。

⏱️

智能阈值

默认观看满 30 秒才记录。可自定义阈值：0 / 10 / 30 / 60 / 120 秒。

🔍

搜索筛选

支持关键词搜索和按平台筛选，快速找到想继续观看的视频。

☁️

加密同步

登录后设置同步加密密码，观看记录和自定义站点会加密后上传，在多台设备之间安全恢复进度。

🌐

自定义站点

除内置平台外，可手动添加任意视频网站域名，通用适配器自动检测 HTML5 播放器。

工作原理

轻量无感，后台默默工作

1

检测视频

Content Script 自动检测当前页面的视频播放器，匹配对应平台适配器。

2

心跳上报

每 5 秒上报一次播放进度到 Background Service Worker，累计观看时长。

3

阈值保存

观看时长超过设定阈值后，自动将视频信息和进度保存到本地存储。

4

继续或加密同步

在 Popup 或 Options 页面查看记录，点击继续观看；登录后输入同步密码即可加密同步记录。

🔒

隐私优先

本地优先，加密同步可控

✓ 未登录时所有数据仅保存在当前浏览器本地
✓ 云端同步为可选功能，需要登录并主动开启
✓ 同步时上传的是加密数据，Supabase 只保存密文
✓ 完全开源，代码可审计
✓ 随时可删除单条记录或卸载清除全部数据
